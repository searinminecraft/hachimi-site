## Tungkol

Ang Hachimi Edge ang pangatlong full-translation mod para sa laro, sinusundan ang footsteps ng UmaTL at Carotene, at ang pinaka-una sa pagsuporta ng game modding sa Android.

Isang fork ng unmaintained na Hachimi mod, nagsimula ito bilang paraan para madaling magbigay ng mga fixes para sa mga isyu pagkatapos ng game update noong 2025/09/24 sa mga user, at mula noon ay isinama na ang mga karagdagang feature at fixes ng iba't ibang community members.
Opisyal na na-discontinue ng developer ng orihinal na Hachimi mod sa 2026/01/17.

## Mga na-modify na game component

Dynamic na ina-apply ang mga pagbabago, hindi kailangan ng asset patching!

- UI text at buttons
- Dynamic na game text (mga skill, pangalan, descriptions, effects, …)
- Game dialogue (main story, pag-interact sa home, kwento ng characters, …)
- Lyrics
- Textures at sprites
- Mga Video

## Mga plugin

Sinusuportahan ng Hachimi Edge ang isang [plugin system](/fil/plugins/about) na nagbibigay-daan sa pagpapalawak ng functionality nito.

## UmaPatcher

Isang helper app ang UmaPatcher Edge para madaling i-patch ang Hachimi Edge sa laro sa Android. Bilang mahalagang bahagi ng Hachimi project, ito rin ay isang fork ng luma at unmaintained na UmaPatcher.
Awtomatikong dina-download ang latest na Hachimi Edge version kapag pina-patch, para wala ka nang ibang alalahanin pa.

## Mga Translation

Ini-index ang mga translation sources mula sa iba't ibang community projects. Nagbibigay ang Hachimi ang isang framework para i-modify ang laro, pero hindi ginagawa o pinapamahala ang mga translations at walang kinalaman sa mga sources na ito.

Hindi nahahanap ang mga translations para sa bagong content? Naghahanap ng ibang wika? Mas marami at up-to-date na mga repositoryo ang ini-index ng Hachimi Edge kaysa sa orihinal.

Tignan ang mga mga sources sa higit pang detalye sa [credits page](/fil/credits) para sa general na impormasyon, progress, tulong at pakikipagugnayan. Subukang suportahan ang mga contributors!
