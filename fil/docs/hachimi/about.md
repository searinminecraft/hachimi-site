# Hachimi <!-- markdownlint-disable-line MD025 -->

[![Discord server](https://dcbadge.limes.pink/api/server/https://discord.gg/hachimimod)](https://discord.gg/hachimimod)

Translation at enhancement mod para sa UM:PD.

![Screenshot](/assets/screenshot.jpg)

## Mga tampok

- **Advanced na formatting:** Ang Hachimi ay may kasamang mga advanced na feature sa pag-translate na tumutulong sa translations na maging mas natural (mga anyong pangmaramihan, mga ordinal na numero, atbp.) at maiwasan ang pagpasok ng jank sa UI.

- **Sinasalin ang karamihang in-game components:** Walang kinakailangang pag-patch ng asset!
  - Text ng UI
  - Dynamic game text mula sa master.mdb (mga skill, pangalan, paglalarawan, epekto, atbp.)
  - Diaylogo sa laro (pangunang kwento, pakikipag-usap sa home, mga kwento ng character, atbp.)
  - Mga liriko
  - Texture & sprite replacement
  - Video replacement
  - Internal game object adjustments
  - Hashed text fallback

Bukod pa rito, ang Hachimi ay hindi nagbibigay ng mga translation features para lamang sa iisang wika; ito ay dinisenyo upang maging ganap na mai-configure para sa anumang wika.

- **Madaling setup:** Plug and play lang. Ginagawa sa laro mismo ang setup, di kailangan ng external application.
- **Translation auto update:** Nagbibigay-daan sa iyo ang built-in translation updater ang paglalaro gaya ng dati habang nag-a-update ito, at nire-reload ito kapag tapos na ito, walang kinakailangang restart!
- **Built-in GUI:** May kasamang config editor para baguhin mo ang mga setting nang hindi umaalis sa laro!
- **Graphics settings:** Maaari mong i-adjust ang graphics ng laro para gamitin ang buong potensyal ng iyong device, tulad ng pag-unlock ng FPS at resolution scaling.
- **Cross-platform:** Dinisenyo para maging portable, na may support sa Windows at Android.
